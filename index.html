SECRET // DEV ROOM

How this world is built

You found the hidden dev room. This whole site is one hand-built page — no game engine, no build step.

EngineThree.js (WebGL), running entirely in the browser
WorldProcedural terrain, water shader, waterfall, seasons and weather — all generated in code
CharactersCustom-built rigged models (the armor you're wearing included), animation clips hand-authored for this skeleton
AudioEvery sound — rain, wind, thunder, footsteps, the waterfall — is synthesized live with the Web Audio API. No audio files.
ProgressOrbs, stops and achievements persist in localStorage

The rest of the experiments live on GitHub.
